# 经营归因分析系统 数据模型设计（可上线级 v1.0）

> 依据：PRD 第 9 章（v1.1）+ 数据实体深化评审（2026-08-18，grill-me）
> 本文档为字段级实现定义，DDL 供初始化基线迁移与开发直接引用。
> 关联文件：`docs/prompts/`（Agent 提示词）、`docs/process/需求评审过程稿.md`（决策脉络）。

---

## 1. 全局约定

| 项 | 约定 | 说明 |
|---|---|---|
| 主键 | UUIDv7，VARCHAR(32) 无横线，应用层生成 | 时间有序、防枚举、可作聚簇索引 |
| 时间 | DATETIME，全库 UTC | 应用层转本地展示；无 2038 问题 |
| 金额 | DECIMAL，不用 FLOAT | llm_calls.cost 用 DECIMAL(10,4) |
| 布尔 | TINYINT(1) | 0/1 |
| 软删除 | 需要保留的表含 `deleted_at DATETIME NULL` | 物理清理见 §5 |
| 外键 | 逻辑外键 + 关联列索引 | 应用层保证一致性，级联删除在应用层 |
| 字符集 | utf8mb4 / utf8mb4_0900_ai_ci | 中文与 emoji 安全 |
| 引擎 | InnoDB | 事务 + 行锁 |

## 2. ER 关系概览

```
auth_users 1 ── N auth_auth_codes / auth_refresh_tokens
auth_clients 1 ── N auth_auth_codes / auth_refresh_tokens

users 1 ── N conversations 1 ── N messages
  │              │                 └── N attachments (message_id 可空)
  │              ├── N analysis_tasks 1 ── 1 analysis_results
  │              │        └── N task_logs / llm_calls
  │              ├── N context_summaries
  │              └── N websocket_tokens
  └── N audit_logs

conversations N ── 1 data_sources（会话可绑定数据源；缺省用内置示例库）
```

## 4. 认证中心表字段级定义

| 表 | 关键列 | 约束 |
|---|---|---|
| auth_users | id PK；username VARCHAR(64)；password_hash VARCHAR(255)（bcrypt/argon2）；display_name；role；status；created_at | UK(username) |
| auth_clients | id PK；client_id VARCHAR(64)；client_secret_hash VARCHAR(255)；redirect_uris JSON；scopes JSON；status；created_at | UK(client_id) |
| auth_auth_codes | id PK；code VARCHAR(64)；client_id；user_id；redirect_uri VARCHAR(512)；scope JSON；expires_at；consumed_at；created_at | UK(code)；5 分钟过期 |
| auth_refresh_tokens | id PK；token_hash VARCHAR(128)；client_id；user_id；expires_at；revoked_at；created_at | UK(token_hash)；IDX(user_id)；7 天 |

## 5. 数据清理任务定义

- **调度**：每日 03:00（UTC），单实例执行（Redis `SETNX` 分布式锁，TTL 30 分钟）。
- **范围与保留期**：

| 对象 | 条件 | 动作 |
|---|---|---|
| 软删业务数据 | `deleted_at < now - 90d`（可配置） | 物理删 conversations/messages/attachments/analysis_tasks/analysis_results/context_summaries/websocket_tokens 记录 + uploads/exports/workspace 对应目录 |
| task_logs | `created_at < now - 90d` | DELETE |
| llm_calls | `created_at < now - 180d` | DELETE |
| websocket_tokens | `expires_at < now` 且未消费 | DELETE |
| auth_auth_codes | `expires_at < now` | DELETE |
| auth_refresh_tokens | 过期或吊销超 30 天 | DELETE |
| audit_logs | 不清理 | 永久保留 |

- **顺序**：先业务软删清理 → 再日志/令牌清理；每批 ≤ 500 行，循环直到清完（避免长事务）；失败重试 3 次并记 WARN，不阻塞当日后续批次。

## 6. 初始化与迁移

- **基线迁移（Alembic）**：`0001_initial` 建全部业务表 + 认证表 + 索引；seed 脚本（幂等）写入：默认 system_configs（含 llm/任务上限/安全限额/功能开关）、预置 data_sources（内置示例库 2 条）、示例数据（场景一/场景二）、默认管理员与示例用户。
- **上线后变更**：新增迁移文件 → `alembic upgrade head`；后端容器启动时自动执行（失败则健康检查不过）。
- **示例数据开关**：`flag_scenario_data`（bool，默认 true）；关闭后 Agent 系统提示词不注入场景 schema、检索不覆盖示例库。

# PRD：经营归因分析系统（P2 Attribution Analysis）

## 1. 背景与目标

### 1.1 背景

企业经营过程中，当出现关键业务指标异常（如销售额下滑、库存积压、转化率下降）时，管理人员需要快速定位问题根因并制定应对策略。传统分析方式依赖人工查询数据库、导出报表、交叉对比，耗时且难以形成系统化的归因结论。

### 1.2 目标

实现一个面向经营分析场景的多轮归因分析系统，支持：
- 围绕一个业务问题持续追问、补充证据
- 生成阶段性结论和最终分析报告
- 通过实时连接展示分析过程中的状态变化和工具执行
- 支持附件上传、结果导出和历史会话管理

### 1.3 成功指标

| 指标 | 目标值 |
|------|--------|
| 单轮分析端到端响应时间 | < 30秒（含LLM调用） |
| 分析任务成功率 | > 95% |
| 结构化输出完整性 | 6个维度100%覆盖 |
| 会话级上下文保持 | 支持至少10轮追问 |
| 结果导出格式支持 | Markdown / JSON |

## 2. 用户角色

### 2.1 分析用户
- 创建会话、输入分析问题、上传资料
- 查看历史消息、查看分析结果、下载结果文件
- 通过多轮对话持续追问，补充数据维度
- 导出分析报告

### 2.2 系统管理员
- 维护认证配置、维护系统配置
- 查看运行日志、管理数据源连接
- 启停功能开关、配置热更新

## 3. 功能需求

### 3.1 认证中心登录（FR-AUTH）
- **FR-AUTH-001**：授权登录入口页，展示登录按钮，点击后跳转认证中心完成授权登录
- **FR-AUTH-002**：登录回调页，处理授权回调参数、换取访问令牌、保存登录态并自动跳转到聊天工作台
- **FR-AUTH-003**：当前Demo阶段支持用户名密码直接登录，管理员账号 `admin/admin123`

### 3.2 会话管理（FR-CHAT）
- **FR-CHAT-001**：创建新会话，支持自定义标题
- **FR-CHAT-002**：会话列表展示，按最近消息时间排序
- **FR-CHAT-003**：会话重命名
- **FR-CHAT-004**：删除会话，级联删除该会话下的消息、附件、任务、结果和上下文摘要
- **FR-CHAT-005**：切换会话，加载历史消息和最近分析结果
- **FR-CHAT-006**：会话状态管理：`active`、`archived`、`deleted`

### 3.3 消息与对话（FR-MSG）
- **FR-MSG-001**：发送分析问题文本
- **FR-MSG-002**：流式渲染AI回复文本（增量推送）
- **FR-MSG-003**：取消正在进行的分析任务
- **FR-MSG-004**：历史消息回放，按序列号排序
- **FR-MSG-005**：一条用户消息对应一次分析任务

### 3.4 实时分析通道（FR-RT）
- **FR-RT-001**：通过WebSocket长连接实时返回中间消息和最终结果
- **FR-RT-002**：实时消息类型覆盖：`message_start`、`message_delta`、`tool_start`、`tool_finish`、`task_status`、`result_ready`、`error`、`done`
- **FR-RT-003**：展示当前分析轮状态、当前步骤、错误信息、工具执行过程和结果文件生成状态
- **FR-RT-004**：同一时间一个会话只允许存在一个运行中的分析任务

### 3.5 附件管理（FR-ATT）
- **FR-ATT-001**：上传附件到当前会话，记录文件名、文件类型、文件大小、上传时间、解析状态
- **FR-ATT-002**：删除附件
- **FR-ATT-003**：下载附件
- **FR-ATT-004**：附件存储路径规范：`uploads/{user_id}/{conversation_id}/`

### 3.6 结果展示（FR-RES）
- **FR-RES-001**：展示六部分结构化分析结果：问题定义、关键指标、证据列表、归因结论、待补充数据、下一步建议
- **FR-RES-002**：关键指标以数组保存，每项包含 `metric_name`、`metric_value`、`metric_unit`、`metric_period`
- **FR-RES-003**：证据列表以数组保存，每项包含 `source_type`、`source_name`、`evidence_text`、`related_metric`、`confidence`
- **FR-RES-004**：下一步建议至少2条
- **FR-RES-005**：支持复制结果内容
- **FR-RES-006**：支持导出结果为Markdown或JSON文件
- **FR-RES-007**：导出文件存储路径规范：`exports/{user_id}/{conversation_id}/`

### 3.7 任务管理（FR-TASK）
- **FR-TASK-001**：分析任务状态流转：`queued` → `running` → `success` / `failed` / `cancelled`
- **FR-TASK-002**：任务日志记录，支持按任务ID查询日志
- **FR-TASK-003**：临时工作文件存储：`workspace/{user_id}/{conversation_id}/`

### 3.8 管理功能（FR-ADMIN）
- **FR-ADMIN-001**：系统配置查看和配置热更新
- **FR-ADMIN-002**：运行日志查看，支持分页
- **FR-ADMIN-003**：配置项包含：LLM模型参数、数据库路径、安全策略等

### 3.9 Text2SQL分析引擎（FR-ENGINE）
- **FR-ENGINE-001**：根据用户自然语言问题生成SQL查询
- **FR-ENGINE-002**：SQL安全守卫，阻止非SELECT语句和危险操作
- **FR-ENGINE-003**：SQL执行引擎，支持结果集限制和重试自修复
- **FR-ENGINE-004**：基于查询结果生成六维度归因分析结论
- **FR-ENGINE-005**：LLM调用失败时提供确定性降级结果

### 3.10 示例业务场景（FR-DEMO）
- **FR-DEMO-001**：库存异常分析场景——提供库存表、入库表、出库表、销量表
- **FR-DEMO-002**：客户行为分析场景——提供用户表、访问事件表、加购事件表、下单事件表
- **FR-DEMO-003**：至少完成两个场景的全链路演示

## 4. 页面结构

| 页面 | 描述 |
|------|------|
| 授权登录入口页 | 展示登录表单，支持用户名密码认证 |
| 聊天工作台页 | 左侧会话列表 + 中间对话区 + 右侧结果区 + 底部输入框 |
| 附件侧栏 | 展示当前会话附件列表，支持上传/删除/下载 |
| 实时任务区 | 展示分析任务状态、步骤、工具执行、错误信息 |
| 结果展示区 | 展示六部分结构化结果，支持复制和导出 |

## 5. 非功能需求

### 5.1 安全性
- 所有API接口需登录态校验
- WebSocket连接需一次性令牌鉴权
- SQL执行引擎强制只读和安全守卫
- 文件上传校验路径安全

### 5.2 可靠性
- 分析任务失败时保留错误信息
- LLM调用失败时提供降级方案
- 数据库操作支持事务回滚

### 5.3 可维护性
- 配置热更新支持
- 模块化代码架构
- 完整的运行日志记录

### 6. 验收标准

1. 能通过授权登录进入聊天工作台
2. 能创建会话、上传附件、发送消息并查看历史记录
3. 能通过实时连接看到分析过程中的状态变化、工具执行和最终结果
4. 能查询历史消息、切换旧会话并继续追问
5. 能在结果区看到六部分结构化输出
6. 能导出分析结果文件并重新下载
7. 能通过配置重载接口更新配置并即时生效
8. 能完成至少两个业务场景的完整演示
